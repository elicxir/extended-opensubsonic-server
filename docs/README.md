# eos サーバーの約束事

eos は OpenSubsonic 互換の音楽サーバーです。サントラ系のコレクションを、作品・楽曲・編曲・関係・仮想アルバムを持つ形で扱えるように拡張しています。このフォルダには、クライアントやツールを作る人が守る約束事（API の形、タグの読み方、同期の手順）をまとめています。

| 文書 | 内容 |
| --- | --- |
| [tags.md](tags.md) | サーバーが読むタグ、独自タグ、ID の決まり方、情報の出どころと優先順位 |
| [rest-api.md](rest-api.md) | OpenSubsonic 互換の `/rest/*`：認証、エラー、エンドポイントごとの振る舞い、トランスコード |
| [ext-api.md](ext-api.md) | 独自拡張の `/ext/*`：読み取り、編集、候補と推定、ログインと API キー、書き出しと読み込み、類似度 |
| [similarity.md](similarity.md) | 曲どうしの類似度の保存（設計と、決めていないこと） |
| [sync.md](sync.md) | `/ext/session`（WebSocket）による共有リモコン、再生回数と音量と ReplayGain の扱い |
| [configuration.md](configuration.md) | 設定ファイルと環境変数 |

## 全体の約束

- サーバーがデータの正本です。クライアントはサーバーの状態を表示し、操作をサーバーに送ります。
- 標準のクライアント（Feishin、Symfonium など）は `/rest/*` だけで動きます。独自の機能は `/ext/*` にあり、`/rest/*` の振る舞いは変えません。
- 認証は `/rest` と `/ext` で共通です。端末ごとに発行する API キーを基本にします。
- 待ち受けポートの既定は `4540` です（Navidrome の 4533 と並べて動かせます）。外部に公開するときは、リバースプロキシで TLS を終端します。
- 時刻は API の中では ISO 8601（UTC）の文字列、同期のメッセージの中では UNIX ミリ秒です。

## 対応するもの・しないもの

- 対応：音楽の閲覧と検索、配信（Range 対応）、トランスコード（Opus・MP3）、ジャケット、お気に入り・評価・再生回数、プレイリスト、再生キュー、独自のデータ（作品・フォルダ・楽曲・編曲・関係・仮想アルバム）、同期。
- 対応しない：Web UI、ポッドキャスト、インターネットラジオ、動画、共有リンク、ジュークボックス、細かな権限（ユーザーは管理者と一般の 2 種類だけ）。

## 版

この文書は M5 時点（サーバー 0.1.0、OpenSubsonic API 1.16.1、`/ext` の `apiVersion` 1）の実装に合わせています。
